# 056: `lastSeenVersion` 0 betyder "okänd"

**Beslut:** migreringen v9 → v10 och nya spel sätter `lastSeenVersion: 0` i stället för det aktuella
byggnumret. UI:t behandlar 0 som "okänd": det sparar då det aktuella bygget (`build` från
`virtual:changelog`) och visar ingen nyhet. Nya spel får bygget direkt i `startApp`.

**Varför:** `src/save/` ska vara ren och en släppt migrering får aldrig ändras. Om migreringen läste
byggnumret skulle den ge olika resultat beroende på vilket bygge som kör den. Med 0 som markering blir
effekten densamma som uppgiften kräver (befintliga spelare möts inte av hela loggen), utan att sparlagret
behöver känna till bygget.

**Alternativ:** importera `build` i `format.ts` (gör migreringen beroende av bygget och svårare att testa),
eller spara versionssträngen (sha:n ändras utan att något nytt finns för spelaren).
