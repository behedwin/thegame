# 107: Läsårets svit räknas från läsårets start

**Beslut:** Den pågående eventsviten (`eventStreak`) fortsätter över "Nytt läsår", men "Längsta svit i år"
(`yearBestStreak`) räknar bara event som lösts i det nya läsåret. Nytt sparfält `yearStreakBase` (sviten vid
läsårets start): `prestige()` sätter det till `eventStreak`, och det nollställs när sviten bryts. Ett löst
event ger `yearBestStreak = max(gammalt, svit - bas)`. `SAVE_VERSION` 19 → 20 med migreringen `19` (basen 0).
Vid laddning klampas basen till högst `eventStreak`.

**Motivering:** Svitbonusen är förtjänad och ska inte försvinna för att spelaren byter läsår (inget
straff, VISION). Men läsårets återblick och jämförelsen med förra läsåret (098) ska vara ärliga: en svit
på 5 som pågår över läsårsbytet ska inte ge "6 i år" efter första eventet.

**Bortvalt:** Nollställa `eventStreak` vid prestige (straffar spelaren och tar bort bonusen mitt i en
svit). Räkna ett separat `yearStreak` som nollställs vid prestige (fler fält att hålla i synk; basen ger
samma sak med ett fält).
